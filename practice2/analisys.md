## 1.Разбор ТЗ
# Сущность Task
Инварианты: 
id - UUID4, title - str, 1–200 символов, status - todo / in_progress / done, created_at - datetime, UTC, timezone-aware, tags -list[str], по умолчанию пустой, priority - int, 1–5, по умолчанию 3

Допустимые операции:
Создание задачи, чтение полей

# Сущность TaskFilter
Инварианты: фильтрация - по по статусу, по тегу, по минимальному приоритету; фильтры комбинируются по «И»
Допустимые операции: создание фильтра

# Сущность ...Ядро
Инварианты: не зависит от конкретной базы данных
Допустимые операции: save(task), get(task_id), delete(task_id), list_all(filter=None)

# Сущность InMemoryRepository
Инварианты: независим от других хранилищ, ядро - мама птица
Допустимые операции: как у ядра

# Сущность JsonFileRepository
Инварианты: независим от других хранилищ, ядро - мама птица
Допустимые операции: как у ядра


|Ошибка            |Область           |
|------------------|------------------|
|TaskNotFound      |Предметная область|
|DuplicateTaskId   |Предметная область|
|StorageError      |Инфраструктура    |
